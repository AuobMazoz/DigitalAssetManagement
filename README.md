# DigitalAssetManagement

Java project demonstrating interfaces and inheritance for digital assets.

## Overview
This project models a small hierarchy of digital asset types using Java object-oriented programming concepts such as interfaces, abstract classes, inheritance, encapsulation, and method overriding.

## Included examples
- `Processable` interface
- `DigitalAsset` abstract base class
- `Image2D`, `AudioAsset`, and `Model3D` subclasses
- `ProjectDemo` for sample output

## Run
Open the project in NetBeans or another Java IDE and run `ProjectDemo`.

This is a simple educational example for understanding how related asset types can share behavior while keeping their own unique properties.
